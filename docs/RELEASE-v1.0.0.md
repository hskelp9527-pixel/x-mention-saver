# 记得 @ · 首个公开版本

有人说「写长文记得 @ 我」，下次却忘了用户名？在 X 上选中 `@用户名`，点旁边的「保存」，以后勾选即可一次复制。

## 这个版本包含

- 选中后在用户名旁边保存，自动避开选中文字。
- 收藏、备注、搜索、编辑和删除。
- 单人或多人一键复制，空格 / 换行两种格式。
- 自动去重及本机 JSON 备份。

## 安装

下载下方的 **x-mention-saver.zip** 并解压。在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择解压文件夹，然后刷新 X。

无需构建，不需要账号。尚未上架浏览器插件商店；界面为简体中文。收藏保存在本机浏览器，卸载前请导出备份。

## 提及通知

批量复制默认包含空格。长帖请把 @ 放在前 280 个字符以内；通知投递还受 X 和对方通知设置影响。

本版本已通过真实插件与模拟 X 页面的浏览器验证，覆盖保存、复制、去重、备注、按钮位置及数据保留；不验证 X 实际通知投递。

English: Download the ZIP, unzip it, enable Developer mode in Chrome / Edge and load the unpacked folder. Save selected X handles, add notes and copy multiple mentions. Local storage only; Chinese interface; MIT license.
